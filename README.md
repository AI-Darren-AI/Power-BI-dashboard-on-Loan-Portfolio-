# Power-BI-dashboard-on-Loan-Portfolio-
•	Analysed 5,000 loans across 3,134 customers (portfolio of 252.6M) in a 3-page Power BI dashboard covering portfolio performance, customer demographics and financial risk, using DAX measures and income and credit-score bucketing.
•	Identified a 10.4% default rate (519 loans, 26.2M), rising from about 9.7% for 2018 loans to 13.3% for 2023 loans.
•	Found that 51% of loans (128M) went to customers with poor credit scores, yet their default rate (9.3%) was lower than for excellent-score customers (12.8%), showing credit score alone did not predict default in this dataset; recommended a multi-factor risk view.
